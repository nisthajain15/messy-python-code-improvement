# Messy Python Code Improvement

## About
This project demonstrates how Python code can be organized into clean, readable, and reusable functions.

## Features
- Calculates the average of student marks.
- Checks whether a student has passed or failed.
- Displays a simple student marks report.
- Uses functions to improve code readability and reuse.

## Technologies Used
- Python 3

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command in the terminal:

```bash
python main.py
```

If `python` doesn't work on Windows, try:

```bash
py main.py
```

## Sample Output
The program displays student marks, their average, and each student's pass/fail status.

## Learning Outcomes
- Writing reusable functions
- Using loops and conditional statements
- Improving code readability
- Organizing a simple Python project
